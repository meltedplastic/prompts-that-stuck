# Nudge Fix Report

**Post a structured, readable fix report to a team Discord channel the moment something is resolved.**

---

## What it does

This one is a full skill rather than a one-paste prompt — it carries and branching instructions. Read [`claude.skill.md`](claude.skill.md) for the complete text.

---

## When to use this

Use when a bug, workflow failure, or system issue has just been fixed and needs to be reported to the team channel — trigger phrases like 'report the fix', 'post the fix to nudge', 'let the team know it's resolved', or right after fixing something that broke a Nudge/Front Desk/n8n system. Not for casual updates or emails (see nudge-notify for email).
